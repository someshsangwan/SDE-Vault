# SDE-Vault

Personal preparation vault for software engineering interviews. Java-focused.

## Structure

| Folder | Contents |
|---|---|
| `DSA/` | Pattern-based DSA notes (one folder per pattern) with Java LeetCode solutions |
| `System-Design/HLD/` | High-level (distributed system) design notes |
| `System-Design/LLD/` | Low-level (object-oriented) design notes |
| `Operating-System/` | OS fundamentals |
| `Computer-Network/` | Networking fundamentals |
| `Behavioral/` | STAR-format interview stories |

## Philosophy

- **Topic-driven, not date-driven** — work when there's time, depth over cadence
- **Fundamentals over summaries** — notes are written to be re-readable months later
- **Java-grounded** — code in Java; OS/networking concepts tied to JVM/Spring Boot where relevant

## Tooling

- Notes in Markdown, organized for [Obsidian](https://obsidian.md/)
- Solutions in Java
- PDFs and copyrighted reference material are gitignored
